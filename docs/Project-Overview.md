# Windows Event Log Security Analysis Lab

## Project Overview

This project demonstrates the analysis of Windows Security Event Logs to identify, investigate, and document authentication-related security events.

Windows Event Logs provide critical visibility into user activities, authentication attempts, system changes, and security incidents. Security analysts rely on these logs to detect suspicious behavior, perform investigations, and support incident response activities.

In this lab, Windows Event Viewer was used to analyze authentication events, investigate failed logon attempts, correlate security events, and document findings using industry-standard methodologies.

---

## Objectives

- Access and analyze Windows Event Logs
- Investigate authentication-related events
- Identify successful and failed logon attempts
- Perform event correlation analysis
- Document security findings
- Map findings to MITRE ATT&CK techniques
- Develop SOC analyst investigation skills

---

## Tools Used

- Windows Event Viewer
- Windows Security Logs
- Log Parser Studio (Optional)

---

## Key Event IDs Investigated

| Event ID | Description |
|-----------|-------------|
| 4624 | Successful Logon |
| 4625 | Failed Logon |
| 4798 | User Account Enumeration |

## Project Outcome

Successfully identified multiple failed authentication attempts followed by successful authentication activity and documented the investigation process using SOC analyst methodologies.
